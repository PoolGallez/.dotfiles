** Control Panel
Platform is auto-detected from =system-type=. Edit the feature flags and paths below — that is the only place you need to touch when setting up a new machine.

*** Platform Detection
#+begin_src emacs-lisp
(defvar glz/platform
  (cond ((eq system-type 'windows-nt) 'windows)
        ((eq system-type 'gnu/linux)  'linux)
        ((eq system-type 'android)    'android)
        (t 'linux))
  "Current platform symbol: windows, linux, or android.")
#+end_src

    "Return non-nil if the buffer content matches testfall grammar patterns."
