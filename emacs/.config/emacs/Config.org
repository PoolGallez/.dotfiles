** GC threshold after startup
minimal-emacs sets gc-cons-threshold to most-positive-fixnum during startup and
restores it afterwards. Override the restore target to 2 MB (matching a typical
Emacs tuning recommendation) instead of the default 32 MB.

** Control Panel
Platform is auto-detected from =system-type=. Edit the feature flags and paths below — that is the only place you need to touch when setting up a new machine.

*** Platform Detection
#+begin_src emacs-lisp
(defvar glz/platform
  (cond ((eq system-type 'windows-nt) 'windows)
        ((eq system-type 'gnu/linux)  'linux)
        ((eq system-type 'android)    'android)
        (t 'linux))
  "Current platform symbol: windows, linux, or android.")
#+end_src

;; On Windows, Emacs GUI does not inherit the system PATH.
;; Add Git's unix tools so diff, grep, find, etc. are available to all packages.
(when (eq glz/platform 'windows)
  (let ((git-bin "C:/Program Files/Git/usr/bin"))
    (when (file-directory-p git-bin)
      (add-to-list 'exec-path git-bin)
      (setenv "PATH" (concat git-bin ";" (getenv "PATH"))))))

  (let ((f (expand-file-name "testfall-mode.el" user-emacs-directory)))

  (defun glz/testfall-buffer-p ()
    "Return non-nil if the buffer content matches testfall grammar patterns."
    (save-excursion
      (save-restriction
        (widen)
        (goto-char (point-min))
        ;; Match patterns that are highly distinctive to testfall files
        (re-search-forward
         (rx (or "<Konzern-Varianten>"
                 (seq "DUT::" (+ (any alpha "_")))
                 (seq "VAR::" (+ (any alpha "_")))
                 (seq "CAL::" (+ (any alpha "_")))
                 (seq bol "Variation:")
                 (seq bol "VarEnd")))
         (min (point-max) 100000)
         t))))

  (defun glz/maybe-enable-testfall-mode ()
    "Enable testfall-base-mode when the buffer contains testfall grammar."
    (when (and buffer-file-name
               (not (string-match-p "\\.org\\'" buffer-file-name))
               (not (derived-mode-p 'testfall-base-mode))
               (glz/testfall-buffer-p))
      (testfall-base-mode)))

  (add-hook 'find-file-hook #'glz/maybe-enable-testfall-mode))

**** CANAPE PAR mode
Syntax highlighting for Vector CANAPE parameter export (=.par=) files.
The mode file self-registers via =auto-mode-alist= for =*.par=, so loading it
here is sufficient.  Faces follow the active theme automatically.

Highlighting summary:
- Parameter names (=IDENTIFIER [TYPE(BITS),(ROWS,COLS)]=) → function-name face
- Type keyword (=INT=, =FLOAT=, …)                        → type face
- Bit width and dimension numbers                          → constant face
- Value-line marker (=:=)                                  → builtin face
- Numeric values                                           → constant face
- Semicolon comments (=; …=)                               → comment face
